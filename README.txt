PERSONAL WEBSITE - MATRIX TERMINAL THEME

Desain diperbarui dengan latar hitam, grid/scanline hijau, panel terminal,
dan susunan halaman yang berbeda dari referensi Bureau81.

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder ini di Visual Studio Code.
3. Jalankan index.html menggunakan Live Server atau browser.

Struktur:
- 6 halaman HTML
- css/style.css
- img/ (ilustrasi SVG lokal)

Ganti link https://your-portfolio-link.com pada more.html dengan link
portfolio pribadi kamu.

Dibuat hanya menggunakan HTML dan CSS, tanpa JavaScript/framework.
