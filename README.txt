Fitur yang Ditambahkan

Digital Clock

Menampilkan jam dan tanggal secara otomatis.

Waktu diperbarui setiap satu detik menggunakan setInterval().

Back to Top

Menambahkan tombol ↑ TOP untuk kembali ke bagian paling atas halaman.

Tombol muncul ketika pengguna menggulir halaman ke bawah.

Menggunakan efek scroll halus (smooth scrolling).

Image Zoom

Menambahkan interaksi klik pada gambar dengan class .project-image.

Gambar dapat diperbesar dan dikembalikan ke ukuran semula.

Menggunakan manipulasi class dan style melalui JavaScript.
